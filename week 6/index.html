The box model

Every element is a rectangle. Adjust the padding, border, and margin in the example below, and use the color key to see what each layer does.

CONTENT width: 100% inside padding

The orange border and green padding are included in the element’s declared size because box-sizing is border-box.

Box model key

  • Margin — 30px of transparent space outside the border.
  • Border — 10px edge around the element.
  • Padding — 20px of space between the border and content.
  • Content — the text or other element content.

CSS in this example

* {
  box-sizing: border-box;
}

.example {
  width: 250px;
  padding: 20px;
  border: 10px solid coral;
  margin: 30px;
}
